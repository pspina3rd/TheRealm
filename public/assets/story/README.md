# Story art

Sprites edited for the story's cinematics. Each is derived from the ElvGames asset pack in
`../elvgames/` and remains under that pack's licence (credit: ElvGames). The originals are never
changed.

Regenerate with `python tools/story-art/make_opening_sprites.py` from the repository root.
