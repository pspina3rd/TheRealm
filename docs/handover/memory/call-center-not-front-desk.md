TheRealm (TLC) is a **call center** game. Agents take calls, work a
blended live/async queue, handle enchanted mail, look up records and
write case notes. Never describe it as a "front desk" — there is no
walk-in counter and nobody greets visitors.

**Why:** Phil has had to correct this in more than one session ("you
keep putting it back in and thinking a call center is also a front
desk"). It signals the writer doesn't understand the job the game is
modelling, which is the project's core subject matter.

**How to apply:** Use "call center", "agent", "the desk" (a
workstation). Check `CLAUDE.md`, `package.json`, `docs/settled.md`
and `src/` for regressions before claiming it's clean. Related:
[[therealm-design-frame]], [[phil-verify-by-reading-output]].
