# M1 author playtest

This is the hands-on acceptance row. Automated runs cannot supply your judgment.
Use GetPutTaco and `npm install` / `npm run dev`. Use a separate browser profile
or private window for the fresh-game checks, keeping your existing adventure.

1. Start a fresh hero. Try Rowan once, without rehearsing. Record win/loss,
   whether the demonstration helped, and whether the stakes were clear.
2. Try Pip, Bean and Ordor. Record each first result; report whether at least
   one was a loss. Do not deliberately fail to satisfy the log.
3. Use Correct once with Rowan or Pip. Check that it returns the last piece,
   feels understandable, and offers no second correction on the same attempt.
4. On a phone, check the board, objectives, Pause, Give up, Correct and spell
   controls. Note any overlap, small target or gesture that behaves unexpectedly.
5. Report confusing rules, tedious waits, out-of-character lines, and whether
   the introductory challenges feel fair. The Moon Wyrm is still the midpoint;
   the continuation and finale remain available in existing campaign saves.

Record date, device, class, first results and observations. The author's M1
**go/no-go is pending**. This file does not assert that unfinished automated
balance gates have passed, and M2a remains off until the agreed go/no-go.
