# Review of story plans A–D

Independent review of the four execution plans in this folder, written as two roles: a narrative
director (story, canon, all-ages literary writing) and a principal gameplay engineer (TypeScript
game code, tests, save compatibility). Branch `GetPutTaco`, 3 November 2026. No plan file, game
code, data or test was changed.

Sources checked: [brief](../reviews/STORY_QUALITY_REVIEW.md), [World Bible](../WORLD_BIBLE.md),
[casting contract](../BOARD_MAGIC_PLAN.md), `docs/STORY.md`, `docs/ENCOUNTER_DESIGN.md`, and the
code and tests named below. About 120 file:line citations were sampled. Most are exact or within
one line; the wrong ones are listed in section 3.

   PD-D01/D02/D03, A-D3 to A-D5, PC-D01. Nothing below that depends on an unanswered decision
   starts. Exit: decisions recorded.

   hygiene half of `tests/storyText.test.ts`. Low risk, no beats move. Exit: `npm run check` and
   reader `--check` pass.

   and test against current text, with known gaps). C's phase 1 (drowsy in the workshop, G1) and
   phase 2 (stone light). No story text changes yet. Exit: G1 passed; ledger test runs.
4. **Plan D structure (if PD-D03 is approved).** D2.x and D4.1–D4.5: cut tasks, new flags and
   scenes, v18 migration, existing tests updated (F-10). Do this before any other plan edits
   underground text, so text is written once. Exit: per-class run and migration tests pass.

   `STORY.md` and `tests/script.test.ts` (F-05). Second half: A's glossary, B's plants on the
   post-D scene list (F-04), D's late rewrites and the five answer points (C-1), all in A's
