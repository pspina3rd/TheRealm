# Mana Crystals — Story Script (Complete & Unabridged)

Oct 24, 2026 · @Philip Spina

## How to use this script

Every word a player reads in the game is here, in the order they meet it, pulled straight from the game's code. Edit any line in place; when you're done, tell me and I'll copy your changes back into the game exactly as written.

- **Columns by attitude.** Townsfolk speak differently depending on how they feel about the hero. Hostile and Wary heroes hear the left column, Neutral the middle, Friendly and Devoted the right.
- **Rows by moment.** Greeting, taking on the task, success, failure and afterwards. Confides and Refuses happen at the extremes (Devoted, Hostile).
- **The line under each name** (element, challenge type, rewards) are game data for context.
- **Rotational Dialogue:** Entries contain multiple bulleted options (`•`) so characters do not repeat the exact same sentence on every turn.
